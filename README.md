# Portfolio Fadila Tanza Meiarfiandhari

Portofolio pribadi berbentuk web interaktif untuk menampilkan identitas, keahlian, proyek, pengalaman, pendidikan, serta kontak untuk kolaborasi.

## Live Preview (Lokal)

Buka file ini langsung di browser:

```text
file:///D:/9router/portfolio-fadila/index.html
```

Atau jalankan via local server (opsional) biar loading lebih smooth:

```bash
# pakai python
py -m http.server 5500

# lalu buka http://localhost:5500
```

## Tech Stack

- HTML5 (Semantic)
- CSS3 (Vanilla CSS, CSS Variables, Flexbox & Grid)
- JavaScript (Vanilla) – IntersectionObserver + Mobile Nav
- Bootstrap Icons
- Google Fonts – Inter

## Fitur

- Hero section dengan CTA
- About Me & Fokus Belajar
- Skills & Tools (Teknis + Soft Skill)
- Projects Highlight (3 proyek placeholder sesuai arahan)
- Experience & Education (RPL + Organisasi Siswa + PMI)
- Contact/Footer dengan link Instagram & GitHub
- Responsive (Mobile–Desktop)
- Micro-animation + Scroll Reveal
- SEO-friendly (meta title/desc, OG, canonical, semantic)
- Aksesibel dasar (skip link, aria-label)
